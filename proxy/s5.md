## 三、🛠️ EMOS 官方要求变量

> 参照 EMOS 官方 Wiki 要求，反代 EMOS 节点时必须添加以下变量。

| 变量名                      | 推荐值       | 是否必填 | 获取来源 / 说明                                              |
| :-------------------------- | :----------- | :------: | :----------------------------------------------------------- |
| `EMOS_FORCE_REAL_IP`        | `1`          |  ✅ 必填  | **固定值**。填 `1` 开启，填 `0` 关闭。开启后，Worker 会强制将访客真实 IP 注入 `X-Real-IP` / `X-Forwarded-For` / `X-FORWARDED-FOR` 三个请求头再发给 EMOS 服务器（EMOS 官方要求必须传递）。源码函数：`applyEmosHeaders()`，`L509`。 |
| `EMOS_IMAGE_CACHE_TTL`      | `86400`      |  ✅ 必填  | **固定值**。单位：秒。填 `86400`（24小时）。对 EMOS 节点的图片接口（`/Images/`、`/items/*/images/`）启用 Cloudflare 边缘缓存，减少回源压力。源码：`fetchInit.cf = { cacheEverything: true, cacheTtl: env.EMOS_IMAGE_CACHE_TTL }`，`L1793`。 |
| `EMOS_MATCH_HOSTS`          | `emos.best`  |  ✅ 必填  | **固定值**。逗号分隔的域名列表（如 `emos.best,cdn.emos.best`）。Worker 用此列表识别哪些目标域名属于 EMOS 节点，只有匹配的请求才会应用 EMOS 专属优化逻辑。源码函数：`isEmosTarget()`，`L493`。 |
| `EMOS_PING_CACHE_TTL`       | `60`         |  ✅ 必填  | **固定值**。单位：秒。填 `60`。对 EMOS 的 Ping/健康检测接口（`/system/ping`）单独设置更短的缓存时间，降低无效心跳对服务器的压力。源码：`L1791`。 |
| `EMOS_PROGRESS_THROTTLE_MS` | `1200`       |  ✅ 必填  | **固定值**。单位：毫秒。填 `1200`。**核心防封控变量**。对播放进度上报接口 `/sessions/playing/progress` 进行节流：同一用户（IP + 设备ID + SessionID 组合）两次上报间隔小于此值时，Worker 直接拦截并返回 `204 No Content`，不回源。源码函数：`shouldThrottleEmosProgress()`，`L581`。 |
| `EMOS_PROXY_ID`             | `e123456789` |  ✅ 必填  | **由 EMOS 服主/官方分配**。通常在加入 EMOS 服时由服主通过面板或 TG 群提供，格式一般为 `e` 开头的字符串。Worker 将其注入请求头 `EMOS-PROXY-ID` 发往上游，用于 EMOS 官方审计溯源。源码函数：`applyEmosHeaders()`，`L504`。 |
| `EMOS_PROXY_NAME`           | `@MyChannel` |  ✅ 必填  | **由 EMOS 服主/官方分配**。你的代理频道/名称标识，通常就是你的 TG 频道 Username（含 `@`）。Worker 将其注入请求头 `EMOS-PROXY-NAME` 发往上游。源码函数：`applyEmosHeaders()`，`L505`。 |

## 九、🚀 流媒体智能分片缓存与边缘加速（开箱即用）

> **💡 说明**：该模块默认内置 **客户端 User-Agent 智能自适应分片算法**：
>
> - 📱 **手机移动端 / 蜂窝网络**（iPhone、Android、Yamby、CapyPlayer 等）：自动分配 **2MB** 分片，兼顾极速秒开、省蜂窝流量与快进零缓冲；
> - 📺 **大屏电视端 / 专业 4K 原盘播放器**（Apple TV、Infuse、VidHub、SenPlayer、TV Box、PC）：自动提升至 **4MB** 分片，保障高码率 4K 原盘稳定吞吐与减少切片请求数。
>
> **无需强制添加任何环境变量即可自动智能运作**！若想全局固定切片大小，可配置以下变量强制覆盖。

| 变量名            | 默认值           | 推荐值                | 是否必填 | 获取来源 / 说明                                              |
| :---------------- | :--------------- | :-------------------- | :------: | :----------------------------------------------------------- |
| `CHUNK_SIZE_MB`   | `自适应 (2/6/8)` | 不填 (或固定 `2`/`4`) |  🔘 可选  | **全局固定切片大小（MB）**。有效范围 1~16。未设置时自动启用起播 2MB 头部秒开 + 后续 6MB/8MB 阶梯降频策略。 |
| `CHUNK_CACHE_TTL` | `604800`         | `604800`              |  🔘 可选  | **自定义数值（秒）**。视频分片在 Cloudflare 边缘缓存（`caches.default`）的保留时长。默认 `604800`（7 天）。 |
| `PREFETCH_DEPTH`  | `2`              | `2` 或 `3`            |  🔘 可选  | **预热前瞻深度窗口（分片数）**。有效范围 1~3。默认 `2`（在播放当前分片时，后台异步提前预热后续 2 个分片，约 12MB~16MB 数据，抵抗地铁/弱网瞬断）。 |

## 九、🔑 CF_API_TOKEN 权限配置指南

> 本节记录 `CF_API_TOKEN` 在 Cloudflare 后台需要开通的所有权限，确保面板所有功能正常运作。

### 创建步骤

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 右上角头像 → **My Profile** → 左侧 **API Tokens** → **Create Token**
3. 选底部的 **Create Custom Token（自定义 Token）**
4. 按下表添加 5 个权限条目
5. Account Resources 选择你的账号，Zone Resources 选 `Specific zone` → 你绑定的域名
6. 点击 **Continue to summary → Create Token** → 复制并保存

### 所需权限清单（共 5 条）

| #    | 第一列（类型） | 第二列（权限名） | 第三列（等级） | 对应功能                                                     |
| ---- | -------------- | ---------------- | -------------- | ------------------------------------------------------------ |
| 1    | **帐户**       | **Workers 脚本** | **编辑**       | Worker 代码读取/更新/覆盖部署、读取绑定信息、修改 Smart Placement 调度设置 |
| 2    | **区域**       | **Workers 路由** | **编辑**       | Worker 自定义路由与域名绑定的读取/添加/更新                  |
| 3    | **区域**       | **清除缓存**     | **清除**       | 面板"一键清除 CDN 缓存"按钮                                  |
| 4    | **区域**       | **DNS**          | **编辑**       | 读取/写入/删除 DNS 解析记录（优选 IP 后更新 DNS 功能）       |
| 5    | **区域**       | **Analytics**    | **读取**       | 流量统计图表（GraphQL 查询区域流量数据）                     |

### 特别说明

- 若只使用反代转发，不需要任何 CF 高级功能，`CF_API_TOKEN` 可以留空，所有依赖它的面板按钮会返回"变量未配置"的友好提示，不影响反代核心功能。
- 旧版全局 API Key（Global API Key，即纯 32 位十六进制字符串）**无法作为 Bearer Token 使用**，必须在后台生成专用 API Token。
- Token 创建后请妥善保管，Cloudflare 只显示一次，丢失后只能删除重建。

## 十、🤖 Telegram Bot Webhook 绑定与触发说明

> 本 Worker 内置完整的 Telegram 机器人交互后端，支持在 TG 内直接管理反代节点、查看系统状态及处理异步菜单。

### 1. Webhook 接口地址

你的 Worker 提供的 Telegram Webhook 接收端点为：

```text
https://<你的Worker域名或自定义域名>/api/tg-webhook
```

### 2. 绑定 Webhook 触发方式

在开启 TG Bot 交互功能前，需要将该接口注册到 Telegram 官方服务器。

#### 方式一：浏览器直接访问注册（最简便）

将下方链接中的 `<TG_BOT_TOKEN>` 替换为你的机器人 Token，`<YOUR_DOMAIN>` 替换为你的域名，然后在浏览器中打开：

```text
https://api.telegram.org/bot<TG_BOT_TOKEN>/setWebhook?url=https://<YOUR_DOMAIN>/api/tg-webhook
```

**成功提示**：浏览器会返回 `{"ok":true,"result":true,"description":"Webhook was set"}`。

#### 方式二：使用 cURL / PowerShell 命令行注册

在终端中运行以下命令：

```bash
curl -s "https://api.telegram.org/bot<TG_BOT_TOKEN>/setWebhook?url=https://<YOUR_DOMAIN>/api/tg-webhook"
```

---

### 3. 检查与测试 Webhook 状态

#### 检查 Worker 端健康状态

直接在浏览器中访问：`https://<YOUR_DOMAIN>/api/tg-webhook` (GET 请求)  
返回示例：

```json
{
  "ok": true,
  "endpoint": "/api/tg-webhook",
  "has_db": true,
  "has_tg_token": true,
  "tg_api_base": "https://api.telegram.org"
}
```

#### 检查 Telegram 官方回调状态

在浏览器访问：

```text
https://api.telegram.org/bot<TG_BOT_TOKEN>/getWebhookInfo
```

---

### 4. 解除 Webhook 绑定

若需要停用机器人 Webhook，在浏览器中访问：

```text
https://api.telegram.org/bot<TG_BOT_TOKEN>/deleteWebhook
```

### 5. TG Bot 支持的命令与触发逻辑

- `/status` 或 点击菜单按钮【📊 查看运行状态】：获取节点运行状态与实时统计图表
- 点击菜单按钮【🌐 获取反代节点】：向机器人获取当前已部署的反代节点列表及跳转链接
- `/cancel` 或 发送 `取消`：随时中断当前的节点编辑/添加会话
